# 取得元ごとの規約メモ（2026-10-30 時点）

| 取得元 | 扱い | 根拠 |
|---|---|---|
| 楽天トラベル（楽天ウェブサービス） | 公式APIで取得する | 楽天ウェブサービスの利用規約に従う。アプリID・アクセスキーが必要。2026年2月の改定でリファラ（Referer）チェックが必須 |
| なっぷ | 許可なしには取得しない | #なっぷNOW 利用規約で、書面承諾なしのデータ収集・複製を禁止。本体規約でも営利目的の利用・アクセスを禁止 |
| 489ban（予約番／キャディッシュ） | キャンプ場ごとに許可を取ってから | 公開されている規約は宿泊施設向けの契約のみ。閲覧者によるデータ取得の定めは見当たらない。空き情報は各キャンプ場のもの |
| じゃらん | 取得しない | 公開APIは未確認 |
| 各キャンプ場の公式サイト | 受付ルール（文章）を人が読んで CSV に書く | 自動取得はしない |

受付開始日は、各キャンプ場が公開している受付ルールから閲覧時に計算している（自動取得ではない）。
